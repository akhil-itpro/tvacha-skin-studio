# Self-hosted Tvacha typography

Original, unmodified font files downloaded on 24 October 2026 from the official
[Google Fonts repository](https://github.com/google/fonts).

- Archivo: variable width and weight, used for headings.
- Atkinson Hyperlegible Next: variable weight, used for readable body copy.
- IBM Plex Mono: regular and medium, used for label data and prices.

The corresponding SIL Open Font License files are included beside the fonts.
See `sources.json` for exact source URLs, byte sizes and SHA-256 checksums.
The CSS definitions are in `app/fonts.css`. Browsers load the fonts from the
same Tvacha origin; no Google Fonts stylesheet or tracking request is needed.
